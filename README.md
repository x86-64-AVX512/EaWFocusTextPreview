# EaW Focus Text Preview 0.7.6F9

Автономное настольное приложение для проверки текста окна национального
фокуса Hearts of Iron IV: Equestria at War. Предпросмотр использует систему
координат `550×550` из `interface/nationalfocusview.gui` и измеряет строки
не системным шрифтом, а метриками `xadvance` из BMFont.

Исходный код распространяется по свободной лицензии [MIT](LICENSE).
Сведения о сторонних зависимостях и игровых ресурсах находятся в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Установка готовой сборки

1. Скачайте архив `EaWFocusTextPreview-<версия>-windows-x64.zip` со страницы
   GitHub Releases.
2. Распакуйте **весь** архив в отдельную папку.
3. Запустите `EaWFocusTextPreview.exe`.

Не переносите один EXE отдельно от `_internal`: сборка выполнена в режиме
`onedir`, поэтому программе нужна вся распакованная папка.

Обычный предпросмотр сразу работает без выбора мода. Папка требуется только
при включении флажка «Подставлять динамическую локализацию»: программа
предложит выбрать её в этот момент. Путь сохраняется в `settings.json` рядом
с EXE, отображается в редакторе и может быть изменён кнопкой «Сменить…».
Путь к моду в реестре Windows не хранится.

Python, Node.js, браузер, локальный сервер и установленная Hearts of Iron IV
для запуска не нужны. Если локальная установка игры найдена, программа может
использовать её оригинальный 18-пиксельный атлас для более точного внешнего
вида; без игры остаётся встроенный переносимый fallback.

## Возможности

- настоящее чтение текстового формата BMFont `.fnt`;
- загрузка DDS через Pillow с преобразованием в RGBA/QImage;
- точечное увеличение bitmap-глифов без размытия обводки и изменения
  `xadvance`;
- русский → English fallback по умолчанию и обратный порядок по выбору;
- расчёт ширины и переносов по `xadvance`;
- перенос по словам и посимвольное деление слишком длинного слова;
- игровые правила висячего многоточия и переноса отдельного `–` вместе со
  следующим словом;
- игровые коды `§Y`, `§G`, `§R`, `§O`, `§H`, `§T`, `§g`, `§!`;
- реальные переводы строк и текстовая последовательность `\n`;
- центрированное описание и эффект с выравниванием влево;
- красная заглушка и диагностика для отсутствующего глифа;
- интерактивная прокрутка эффекта колесом мыши;
- зелёная, жёлтая и красная диагностика переполнения;
- консольный JSON-арбитр для ИИ, скриптов и пакетных проверок;
- двусторонний named pipe API запущенного окна.
- отключённая по умолчанию динамическая/scripted локализация из выбранного
  мода;
- автоматические встроенные `GetName`, `GetNameDef`, `GetAdjective`,
  `GetLeader`, названия столиц, фракций, партий и даты;
- подбор худшей допустимой подстановки по реальной bitmap-раскладке.

Динамическая локализация экспериментальна, очень нестабильна и может заметно
увеличивать нагрузку на компьютер. GUI показывает это предупреждение рядом с
переключателем. Пока переключатель выключен, токены остаются в исходном виде,
а папка мода не нужна.

При включении токены вроде `[Root.ABY_royal_loc_nocap]` сопоставляются с
`defined_text` из
`common\scripted_localisation`, затем со значениями выбранного языка из
`localisation`. Если возможно несколько значений, программа проверяет их
комбинации и подставляет вариант, который занимает больше всего места в
конкретном поле. Поэтому проверка остаётся консервативной. Для встроенных
`[Root.GetName]` и подобных функций варианты собираются из локализации стран,
косметических тегов, персонажей, регионов, фракций и партий выбранного мода.
Переменные `[?variable]` не подменяются. Нераспознанные выражения не скрываются
и перечисляются под диагностикой.

Описание не обрезается отдельной маской на высоте 70 или перед панелью
«Эффект». Сначала оно рисуется полностью, затем поверх него рисуются плашка
и текст эффекта. Итоговая картинка обрезается только внешней границей
`550×550`.

## Разрешённые шрифты

В `assets\fonts` включены только четыре пары `.fnt`/`.dds` из мода:

- `eaw_diplo_16mbs`;
- `eaw_diplo_16mbs_cryllic`;
- `hoi_24header`;
- `eaw_24header_cryllic`.

Системные TTF не участвуют в отрисовке игрового окна. Они могут
использоваться самой оболочкой редактора PySide6.

Загрузчик сначала пробует имя страницы из `.fnt`, затем DDS с именем самой
`.fnt`. Поэтому ссылка `eaw_diplo_16mbs_cryllic_0.dds` корректно
разрешается в существующий `eaw_diplo_16mbs_cryllic.dds`.

Для описания фокуса `nationalfocusview.gui` запрашивает базовый
`hoi_18mbs` размером 18 px: `maxWidth = 485` и `borderSize.x = 5` дают
полезную ширину 474 px с учётом внутреннего пикселя `instantTextboxType`.
В приложение не копируются шрифты базовой игры. Если локальная установка
HoI4 найдена в библиотеке Steam (или указана переменной `HOI4_INSTALL_DIR`),
описание рисуется прямо из её исходного 18-пиксельного атласа `hoi_18mbs` без
масштабирования. Это убирает ступенчатость, вертикальные сдвиги и слипание
контуров.

Готовый игровой растр 550×550 привязывается к целым физическим пикселям
монитора. Поэтому системный масштаб Windows 125%, 150%, 200% и другие
значения не размывают предпросмотр; если на экране физически не хватает
места, холст пропорционально уменьшается. Три последовательные точки
визуально раздвигаются внутри отрисовщика без изменения их метрик, ширины
строки или места переноса.

Поиск выполняется в следующем порядке:

1. переменная среды `HOI4_INSTALL_DIR`;
2. `InstallLocation` приложения Steam `394360` и пути клиента Steam из
   реестра Windows;
3. стандартные каталоги `Program Files`;
4. дополнительные библиотеки из `steamapps\libraryfolders.vdf`.

Реестр используется только для чтения уже существующих записей Steam: путь к
игре туда не записывается. Если оригинальные шрифты не найдены либо не могут
быть загружены, GUI показывает жёлтую предупреждающую плашку и продолжает
работать на встроенном fallback.

При отсутствии игры остаётся переносимый fallback: разрешённый EaW-атлас
16 px увеличивается до `18/16`, причём служебный двухпиксельный padding BMFont
остаётся фиксированным и масштабируется только полезная область глифа.
В обоих режимах изображение глифа не участвует в раскладке: ширина и переносы
по-прежнему считаются одним и тем же точным `xadvance` от `hoi_18mbs`.

## Загрузка текста

Поддерживаются `.txt`, `.yml` и `.yaml`.

Обычный файл без разметки загружается в поле эффекта. Для заполнения всех
трёх полей можно использовать секции:

```text
[title]
НАЗВАНИЕ ФОКУСА

[description]
Описание фокуса.

[effect]
§YЦветной эффект§!
```

Для локализационного YAML распознаются ключи, заканчивающиеся на
`_name`, `_title`, `_desc`, `_description`, `_effect` и `_reward`.

## Интеграция с Notepad++

В готовой папке откройте `Notepad++ Integration`, закройте Notepad++ и
запустите `Install_NotepadPP_Integration.bat`. Для установки в
`Program Files` Windows запросит права администратора. Затем снова откройте
Notepad++.

Чтобы перенести строку локализации, зажмите **Alt** и дважды щёлкните левой
кнопкой мыши внутри текста в двойных кавычках:

```yaml
BAL_focus_desc:0 "Армия: §Y+5%§! Attack"
```

В поле «Описание» попадёт только содержимое кавычек. Обычный двойной щелчок,
`Ctrl`/`Shift` + двойной щелчок и команды меню текст не передают:
**Alt + двойной ЛКМ — единственный способ отправки**. Если приложение закрыто,
плагин запускает его сам. После перемещения готовой папки повторно запустите
установщик, чтобы обновить сохранённый путь к EXE.

Для строк локализации границами значения считаются внешние кавычки. Поэтому
внутренние неэкранированные кавычки, например `"финансирует"`, не обрывают
передаваемый текст.

Плагин рассчитан на 64-битный Notepad++ и находится в
`Notepad++ Integration\EaWFocusBridge.dll`.

## Интеграция с ИИ и другими программами

В готовую папку входит `EaWFocusTextPreviewCLI.exe`. Он проверяет один текст,
JSON-файл, пакет JSON или поток JSONL без запуска видимого окна. Результат
машиночитаемый, а код завершения равен `0` для прошедшего текста, `1` для
непоместившегося и `2` для ошибки:

```bat
EaWFocusTextPreviewCLI.exe check --description "Армия: +5% Attack" --pretty
```

Динамическая локализация в CLI также выключена по умолчанию. Обычная проверка
не требует `settings.json`. Для её включения добавьте
`--dynamic-localisation`; тогда CLI читает путь мода из `settings.json` рядом
с EXE и завершает проверку кодом `2`, если путь не выбран или недействителен.
`--no-dynamic-localisation` позволяет явно отключить настройку из входного
JSON. Язык задаётся через `--language russian`; по умолчанию используется
русский.

```bat
EaWFocusTextPreviewCLI.exe check request.json --dynamic-localisation --pretty
```

К уже запущенному GUI можно обратиться командой `send`; ключ `--show`
одновременно вставит запрос в редактор:

```bat
EaWFocusTextPreviewCLI.exe send Integration\request.example.json --show --pretty
```

Для прямого подключения сторонних программ доступен двусторонний Windows
named pipe `EaWFocusTextPreview.API.v1`. Полный формат запросов, пакетный
режим, политики `visual`/`strict`, коды завершения и структура результата
описаны в `Integration\README_Integration.md`.

## Запуск из исходников

Для разработки требуется Python 3.12 или новее.

1. Запустите `run_dev.bat`.
2. При первом запуске будет создано `.venv` и установлены зависимости из
   `requirements.txt`.

Ручной эквивалент:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

Локальный `settings.json` намеренно исключён из Git. При необходимости можно
скопировать `settings.example.json` в `settings.json` или выбрать папку мода
через GUI при включении динамической локализации.

## Тесты

```bat
.venv\Scripts\python -m pytest
```

Набор из 50 автоматических тестов покрывает парсер `.fnt`, исправление имени
DDS, цветовые коды, переносы, длинные слова, смешанный текст
`Армия: +5% Attack`, русский → английский fallback, динамическую локализацию,
CLI/API, плагин и описание, уходящее под панель. Калибровочные тесты содержат
168 точных русских и 100 английских игровых эталонов, а также подтверждённые
классификации дополнительных OCR-прогонов.

## Сборка

Запустите `build_exe.bat`. Скрипт через установленный Visual Studio C++
собирает и тестирует 64-битный плагин Notepad++, устанавливает Python-
зависимости, выполняет Python-тесты и запускает PyInstaller с
`EaWFocusTextPreview.spec`.

Результат:

`dist\EaWFocusTextPreview\EaWFocusTextPreview.exe`

Рядом создаётся консольный арбитр:

`dist\EaWFocusTextPreview\EaWFocusTextPreviewCLI.exe`

Обе сборки сделаны в режиме `onedir`. Восемь файлов шрифтов добавляются
автоматически. При запуске EXE путь к ним определяется через
`sys._MEIPASS`, при запуске исходников — относительно корня проекта.

## Подготовка GitHub Release

Публичный архив создаётся командой:

```bat
package_release.bat
```

Скрипт выполняет полную сборку, переносит готовые файлы во временную папку,
гарантированно исключает пользовательский `settings.json`, добавляет лицензию
и уведомления о сторонних компонентах, а затем создаёт в `release`:

- `EaWFocusTextPreview-<версия>-windows-x64.zip`;
- соответствующий файл `.sha256`.

Если `build_exe.bat` уже был успешно выполнен, повторную сборку можно
пропустить:

```bat
package_release.bat -SkipBuild
```

EXE, DLL, `dist`, `build`, `release`, локальные настройки и диагностические
изображения исключены из Git. Готовый ZIP публикуется как вложение GitHub
Release, а не коммитится в исходный репозиторий.

## Структура

- `eaw_focus_preview\bmfont.py` — BMFont, DDS, каскад шрифтов;
- `eaw_focus_preview\layout.py` — коды цвета, измерение и переносы;
- `eaw_focus_preview\renderer.py` — QPainter-отрисовка глифов;
- `eaw_focus_preview\focus_canvas.py` — окно фокуса 550×550;
- `eaw_focus_preview\dynamic_localisation.py` — scripted localization и
  подбор худшей подстановки;
- `eaw_focus_preview\automatic_localisation.py` — конечные варианты
  встроенных `Get…`;
- `eaw_focus_preview\mod_settings.py` — переносимый `settings.json`;
- `eaw_focus_preview\main_window.py` — редактор и диагностика;
- `eaw_focus_preview\notepad_bridge.py` — локальный канал приёма из Notepad++;
- `eaw_focus_preview\validation_api.py` — общий JSON-результат проверки;
- `eaw_focus_preview\integration_api.py` — двусторонний named pipe API;
- `cli_main.py` — консольная и пакетная проверка;
- `eaw_focus_preview\file_loader.py` — импорт TXT/YML/YAML;
- `eaw_focus_preview\paths.py` — пути исходников и PyInstaller;
- `notepadpp_plugin\` — исходники, C++-тест и установщик плагина;
- `tests\` — автоматические проверки.
