# Bitmap-шрифты

Эта папка содержит восемь файлов BMFont (`.fnt` + `.dds`), необходимых для
переносимой отрисовки без установленной Hearts of Iron IV:

- `eaw_diplo_16mbs`;
- `eaw_diplo_16mbs_cryllic`;
- `hoi_24header`;
- `eaw_24header_cryllic`.

Это сторонние ресурсы Equestria at War/Hearts of Iron IV, распространяемые в
этом проекте с разрешения команды EaW или от её имени. Лицензия MIT в корне
репозитория относится к коду проекта и не переоформляет эти файлы под MIT.
Сведения об атрибуции находятся в `THIRD_PARTY_NOTICES.md`.

Атласы базовой игры `hoi_18mbs` сюда не включены. Если Hearts of Iron IV
установлена локально, программа обнаруживает эти атласы во время запуска и
использует их только для более точной отрисовки текста.
