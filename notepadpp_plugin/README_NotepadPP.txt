EaW Focus Bridge 0.7.7F1
======================

1. Закройте Notepad++.
2. Запустите Install_NotepadPP_Integration.bat.
3. Подтвердите запрос Windows на права администратора, если Notepad++
   установлен в Program Files.
4. Откройте Notepad++ и EaW Focus Text Preview.
5. Зажмите Alt и дважды щёлкните ЛКМ внутри текста в двойных кавычках.

В строке локализации плагин передаёт значение между внешними кавычками.
Внутренние неэкранированные кавычки вроде "финансирует" текст не обрывают.

Это единственный способ отправки текста из Notepad++.
Обычный двойной щелчок, Ctrl/Shift + двойной щелчок и команды меню ничего
не передают.

Если EaW Focus Text Preview закрыт, плагин запускает его автоматически.
После перемещения папки программы повторно запустите установщик, чтобы
обновить путь к EXE.

Плагин предназначен для 64-битного Notepad++.
