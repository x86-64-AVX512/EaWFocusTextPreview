# Участие в разработке

Спасибо за интерес к EaWFocusTextPreview.

## Среда разработки

- Windows 10/11 x64;
- Python 3.12 или новее;
- Visual Studio с компонентом **Desktop development with C++** — только для
  сборки плагина Notepad++.

Запуск приложения из исходников:

```bat
run_dev.bat
```

Полная проверка Python-кода:

```bat
.venv\Scripts\python -m pytest -q
```

Проверка и сборка плагина:

```bat
notepadpp_plugin\build_plugin.bat
```

Перед отправкой изменения убедитесь, что в коммит не попали `settings.json`,
сборочные каталоги, EXE/DLL и абсолютные локальные пути. Изменение логики
переноса должно сопровождаться игровым эталоном и регрессионным тестом.

Исходный код проекта принимается на условиях MIT. Отправляя изменение, автор
соглашается распространять его на условиях файла `LICENSE`.
